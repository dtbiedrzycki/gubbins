# Browser Tab Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every page of the web app shows the moss-and-gold gift in the browser tab, and `/favicon.ico` returns a real icon.

**Architecture:** Two static files in `apps/web/public/` that Vite copies into the build, and two `<link rel="icon">` tags in `apps/web/index.html`. The API's existing `@fastify/static` registration serves them in production. No code or server changes.

**Tech Stack:** Vite static `public/` directory, Fastify `@fastify/static`, hand-written SVG, a multi-size ICO.

**Spec:** `docs/superpowers/specs/2026-11-02-tab-icon-design.md`

## Global Constraints

- Box and lid moss `#34603F`; ribbon and bow gold `#D9A93A`; no background, outline or other colour.
- No emoji anywhere in the icon, including emoji text inside an SVG.
- Nothing outside the repo: no CDN, external font or remote image.
- The tool that exports the ICO is not added to `package.json`, and there is no build step for it.
- ICO sizes are exactly 16, 32 and 48 pixels, with a transparent background.
- Tag order: ICO first with `sizes="32x32"`, SVG last with `type="image/svg+xml"` and no `sizes`.
- At most 10 files per PR.

## Review Focus

1. **Production serving.** `GET /favicon.ico` and `GET /favicon.svg` on a production build return the icons with image content types, not `index.html` (Task 2, Step 4).
2. **Transparency.** Every ICO size keeps a transparent background, so no white square shows in a dark tab bar (Task 2, Step 2).
3. **Chrome's choice.** Chrome requests the SVG and not the ICO when both are declared (Task 2, Step 4).
4. **Small-size legibility.** At 16 pixels the gift still reads as a gift (Task 2, Step 2).
5. **No emoji or external reference** in either file (Task 2, Step 2).

There are no automated tests. The spec rules them out: nothing here is a decision that code owns.
