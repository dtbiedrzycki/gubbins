What changes in the code

  • New values in the @theme block of index.css. The token names stay the same, plus one token for the list's name, which only the list page's heading picks up.
  • Shrikhand replaces IM Fell English for headings. Alegreya Sans stays for body text.
  • The vine becomes three rounded stripes (--list-rule). The door and the wax seals keep their shapes.
