Putting gifts in order

The owner moves a gift with a two-by-two block beside it on the manage page. The buttons work: tap them to try. Guests see the same order (right). New gifts land at the top, just below the add form.

Manage page · move buttons beside each giftThe top row moves the gift up: one spot, or all the way to the top. The bottom row moves it down: one spot, or all the way to the bottom. Gifts stay the same height as now.
