# .devcontainer/secrets/

Per-developer commit-signing material. **Everything here is git-ignored
except this README and `signing.env.example`.**

| File | What it is |
|---|---|
| `signing.env` | Your `SIGNING_NAME` / `SIGNING_EMAIL` (copied from `signing.env.example`). Git-ignored. |
| `signing_ed25519` / `.pub` | The SSH signing keypair generated by `scripts/setup-signing.sh`. The private key never leaves this machine. Git-ignored. |

This directory lives on the workspace bind mount, so its contents
survive dev-container rebuilds. `~/.ssh` does not — that's why the key
is kept here.

The **public** trust list — which keys may sign commits — is not here.
It is [`/.allowed_signers`](../../.allowed_signers) at the repo root,
committed to version control. See
[`docs/commit-signing.md`](../../docs/commit-signing.md).

Set up (or re-set-up after a rebuild):

```sh
cp signing.env.example signing.env   # then edit
bash ../../scripts/setup-signing.sh
```
